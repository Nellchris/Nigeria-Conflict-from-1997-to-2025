**Nigeria Conflict StoryMap (1997–2025)**
Link: https://nellchris.github.io/Nigeria-Conflict-from-1997-to-2025/
This project presents an interactive conflict StoryMap of Nigeria (1997–2025) built with Leaflet.js, Scrollama.js, and GeoJSON, combining narrative storytelling with spatial analytics. As users scroll through the chapters, the map automatically highlights and animates transitions to each geopolitical region—North Central, North East, North West, South East, South South, and South West—while tooltips and hover effects display event and fatality statistics. Smooth region-label fades ensure emphasis during transitions, and the StoryMap concludes with an integrated choropleth visualization showing cumulative fatalities across all states. The project provides an engaging, data-driven way to explore long-term conflict patterns using ACLED-based aggregates.
